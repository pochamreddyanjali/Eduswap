 🎓 EduSwap

🚀 A student-powered platform for sharing skills, helping others, and building meaningful networks

**Overview**

EduSwap is a web-based platform that connects students to **learn, share, and grow together**.
Users can exchange skills, donate or purchase items, and build strong networks based on interests, location, and expertise.

**Features**

🔐 **User Authentication**

* Secure login & registration using Firebase Authentication

🤝 **Networking System**

* Connect through **skills**, **location**, and **profiles**
* Discover like-minded students

📚 **Skill Sharing Platform**

* Share skills for free
* Sell skills to others
* Learn from experts

🛍️ **Marketplace**

* Donate unused items
* Buy or sell products easily

📊 **Real-time Database**

* Data stored and updated instantly using Firebase Firestore

---

## 🛠️ Tech Stack

* 🌐 HTML, CSS, JavaScript
* 🔥 Firebase Authentication

## 🚀 How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/your-username/Eduswap.git
```

2. Open the project folder

3. Run using Live Server (VS Code extension)

## 🔐 Firebase Setup

* Create a Firebase project
* Enable Authentication (Email/Password)
* Create Firestore Database
* Replace Firebase config in `firebase.js`
